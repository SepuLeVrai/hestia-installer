## Direction retenue

- fenêtre centrale premium et sobre ;
- identité HESTIA chaleureuse ;
- illustration à gauche ;
- contenu fonctionnel à droite ;
- palette ivoire, crème, brun, bordeaux et cuivre ;
- progression visible ;
- boutons Précédent, Suivant et Annuler ;
- animations courtes ;
- responsive ;
- aucun CDN ou asset distant requis au runtime final.

L'image de simulation est une référence de conception. Le runtime final doit utiliser uniquement des assets locaux dont l'usage est validé.
